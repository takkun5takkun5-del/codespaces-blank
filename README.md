# Chromium搭載　デスクトップ環境 

このボタンを押すだけで、最初からブラウザ（Chromium）がインストールされた、あなた専用のLinuxパソコン（デスクトップ環境）がブラウザの中に爆誕します(?)

## 🚀 起動方法

1. 画面右上にある **「Create codespace」** という緑色のボタンを押します。
2. パソコンの準備が始まるので、画面が立ち上がるまで1〜2分ほど待ちます。
3. 画面が起動したら、右下の「ポート (Ports)」タブを開くか、ポップアップに出る **「ブラウザで開く (Open in Browser)」** を押して、noVNCのデスクトップ画面を開きます。

## 🌐 ブラウザ（Chromium）の開き方

1. デスクトップ画面にある **「Web Browser」** のアイコンをダブルクリックします。
2. これでChromiumが起動します！Google検索やJavaScriptが必要なサイトもすべて自由に動かせます。

## ⚠️ 注意事項
* 使うにはGitHubのアカウント（無料）が必要です。
* 使い終わったら、ブラウザのタブを閉じて大丈夫です（しばらく動かさないと自動で停止して無料枠を節約してくれます）。
